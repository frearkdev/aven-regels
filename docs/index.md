## 14. Sancties en straffen { #hoofdstuk-14 }

<p class="hoofdstuk__intro">De onderstaande strafmaat geeft aan welke consequenties kunnen volgen. De uiteindelijke straf hangt af van ernst, omstandigheden, bewijs en eventuele herhaling.</p>

<div class="regels" markdown>

<div class="regel regel--sanctie sanctie--waarschuwing" markdown>

### Waarschuwing { #waarschuwing }

- Kleine overtredingen
- Eerste lichte FailRP
- Onnodige OOC-communicatie
- Kleine verstoringen van roleplay

</div>

<div class="regel regel--sanctie sanctie--taakstraf" markdown>

### Taakstraf { #taakstraf }

- Lichte FailRP: 25–50 taken
- Mixing: 25–50 taken
- Lichte Powergaming: 50–100 taken
- Onnodig Copbaiting: 50–100 taken
- Herhaaldelijke kleine overtredingen: 100–150 taken

</div>

<div class="regel regel--sanctie sanctie--kick" markdown>

### Kick { #kick }

- Het bewust verstoren van een lopende situatie
- Herhaaldelijk ongewenst gedrag
- Het niet opvolgen van een redelijke aanwijzing om een situatie te beëindigen

</div>

<div class="regel regel--sanctie sanctie--tijdelijke-ban" markdown>

### Tijdelijke ban { #tijdelijke-ban }

- RDM: 1–3 dagen
- VDM: 1–3 dagen
- Metagaming: 1–3 dagen
- FearRP/NVL: 1–2 dagen
- Combat Logging: 1–3 dagen
- Revenge Killing: 1–3 dagen
- Herhaaldelijke ernstige FailRP: 3–7 dagen
- Ernstige verstoring van roleplay: 3–7 dagen

</div>

<div class="regel regel--sanctie sanctie--lange-tijdelijke-ban" markdown>

### Lange tijdelijke ban { #lange-tijdelijke-ban }

- Herhaaldelijke overtredingen: 7–14 dagen
- Bewust misbruiken van exploits: 7–30 dagen
- Ernstige OOC-bedreigingen: 7–30 dagen
- Bewust omzeilen van eerdere sancties: 14–30 dagen

</div>

<div class="regel regel--sanctie sanctie--permanente-ban" markdown>

### Permanente ban { #permanente-ban }

- Cheats of modmenu's gebruiken
- Ernstige exploits bewust verspreiden of gebruiken
- Doxxing of privégegevens verspreiden
- Een permanente ban omzeilen
- Ernstige en herhaaldelijke overtredingen
- In-game bezittingen verkopen voor echt geld

</div>

<div class="regel regel--sanctie sanctie--aanvullende-sancties" markdown>

### Aanvullende sancties { #aanvullende-sancties }

- Inbeslagname van illegaal verkregen goederen
- Verwijdering van onrechtmatig verkregen geld
- Verwijdering van voertuigen of bezittingen
